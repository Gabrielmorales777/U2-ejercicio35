# U2-ejercicio35
### Sistema de Cálculo de Costos de Envíos

**Objetivo principal:** Desarrollar un sistema modular en Java que permita calcular los costos de envío de encomiendas utilizando diferentes estrategias de transporte.

Se implementa una clase abstracta `EstrategiaEnvio` y tres clases concretas (`EnvioEstandar`, `EnvioExpresoAereo` y `EnvioMaritimo`), cada una con su propia fórmula de cálculo.

El ejercicio aplica **abstracción, herencia, polimorfismo y sobrescritura de métodos**, incorporando validaciones para evitar pesos y distancias negativos.
